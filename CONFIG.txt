# =============================================================================
# CONFIG.txt - every file path used by Parts 3-10 of the pipeline
# =============================================================================
# One KEY="value" per line. A value may use ${KEY} to refer to a key defined
# ABOVE it (or to an environment variable such as ${HOME}). Comments go on their
# own line. The file is valid bash, so it is read by
#   SLURM job scripts : source CONFIG.txt, found from the script's own location (sbatch from any folder)
#   Python scripts    : from pfn_config import cfg   ->  cfg["KEY"]   (pfn_config.py)
#   R scripts         : cfg$KEY                                       (pfn_config.R)
# Python/R scripts find this file at the repo root on their own.
#
# Layout: the project folder holds the git repo (code/) and three data folders that
# sit outside the repo, so git never tracks them:
#   PROJECT_DIR/code/              this repo (CODE_DIR)
#   PROJECT_DIR/inputs/            copied from CUBIC
#   PROJECT_DIR/reference_files/   downloaded reference files
#   PROJECT_DIR/results/           everything the pipeline writes
# The setup script in ADDING_ACE.md creates them.
# =============================================================================
